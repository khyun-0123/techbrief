# 03. 위협 · 기회 판정과 기술 단계 — AI가 아니라 규칙

> **이 문서로 알 수 있는 것**
> * 보고서 헤드라인의 「자사 기회 · 위협」이 어떤 숫자에서 나오는지
> * 기술 단계(신생 · 성장 · 성숙 · 감소)를 어떻게 정하는지
> * 판정을 어떻게 검증했고, 남은 한계는 무엇인지

## 1. 왜 규칙인가

GPT 같은 생성형 AI는 「기회인가요?」에 그럴듯하게 **말로** 답합니다. 하지만 자사 · 경쟁사 특허를 직접 세지 않고, 같은 질문에도 답이 달라질 수 있습니다. 테크브리프는 **쌓아 둔 특허 127만 건을 규칙으로 세어** 판정합니다. 같은 키워드면 언제나 같은 결과이고, 숫자가 그대로 근거가 됩니다.

## 2. 예: 마이크로LED → 「자사 기회」

1. 키워드 「마이크로LED」가 든 특허의 **45% 이상이 몰린 세부 기술 분류**를 찾는다 → 「마이크로 · 미니 LED」 (127만 건 → 1.5만 건)
2. 그 분류 안에서 **2020~22년 대비 2023~25년** 증가 배수를 분야 · 경쟁사 · 자사별로 센다

| | 2020~22 → 2023~25 | 배수 |
| :-- | --: | --: |
| 분야 전체 | 18,523 → 15,405건 | 0.83배 (줄어듦) |
| 경쟁사 최고 | 992 → 1,461건 | 1.47배 |
| **자사 (고객사)** | **270 → 553건** | **2.03배** |

3. 분야가 줄어드는데 자사가 경쟁사 모두보다 빠르게 늘었다 → **「자사 기회」**

## 3. 기준

| 기준 | 내용 (팀이 정한 출발값 — 담당자 검수 뒤 다시 맞춤) |
| :-- | :-- |
| 기회 | 자사가 경쟁사 모두보다 빠르고, 분야 증가 이상 |
| 위협 | 경쟁사 하나가 분야 증가의 1.5배 이상 + 자사는 분야보다 느림 |
| 판정하는 경우 | 그 말이 든 특허의 45% 이상이 한 세부 기술 분류에 몰릴 때만 (아니면 판정하지 않음) |
| 배수 계산 | 같은 발명(패밀리)은 한 번, 양쪽에 5건씩 더해 작은 수 보정, 두 기간 합 10건 미만은 비율 없음 |
| 해외 출원 비율 | 2개국 이상에 낸 비율을 함께 표시 (중요한 발명인지 참고) |

## 4. 기술 단계

| 단계 | 기준 |
| :-- | :-- |
| 개발 신호 | **특허 먼저**, 특허가 적으면 논문 · 기업 저자 비율 |
| 성장 | 앞 기간보다 1.3배 넘게 늘면 (분야 전체 증가 대비) |
| 감소 | 정점의 60% 아래 |
| 신생 · 탐색 | 연구 기관 3곳 미만 |
| 판단 안 함 | 특허 10건 미만 |

* 재료: 논문 수(2000년~, OpenAlex) · 기업 저자 비율 · 특허(디스플레이 특허 DB) · 검색 관심도.
* AI는 이 숫자를 **글로 옮기기만** 한다 (배경 · 성장 · 적용 · 전망 · 우리가 볼 것). 숫자가 없는 문장은 「AI 해설」로 표시.

## 5. 검증 — 12개 기술

| 기술 | 기대 (팀 초안) | 판정 | 맞음 |
| :-- | :-- | :-- | :-: |
| PDP | 정체 · 감소 | 정체 · 감소 | ○ |
| LCD | 성숙 / 정체 · 감소 | 성숙 · 상용화 | ○ |
| OLED | 성숙 · 상용화 | 성숙 · 상용화 | ○ |
| QD-OLED | 성장 · 상용화 진입 | 성장 · 상용화 진입 | ○ |
| 탠덤 OLED | 성장 · 상용화 진입 | 성장 · 상용화 진입 | ○ |
| 마이크로 LED | 성장 · 상용화 진입 | 성장 · 상용화 진입 | ○ |
| 페로브스카이트 LED | 연구 성장 | 연구 성장 | ○ |

| LTPO | 성숙 / 성장 · 상용화 진입 | 성장 · 상용화 진입 | ○ |

* 특허 DB를 받기 전 **7개** → 받은 뒤 **10개** 맞음. 성숙 기술(LCD · OLED)을 「연구 중」으로 판정하던 문제를 특허로 고쳤다.

## 6. 한계 (먼저 말씀드립니다)

* 규칙을 고친 뒤 **같은 12개로 다시 검증**했기 때문에 실제보다 좋게 보일 수 있다 → 새 기술 · 담당자 판정으로 다시 확인할 것.
* 특허는 **제목 · 기술 분류**로 센다 (초록 전체 검색은 일부만).
* 기준값(1.3배 · 1.5배 · 45%)은 팀이 정한 출발값 → 담당자 검수로 맞춘다. 관리 페이지에서 바꿀 수 있다.
