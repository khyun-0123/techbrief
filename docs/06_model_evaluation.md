# 06. AI 모델 평가

> **이 문서로 알 수 있는 것**
> * 어떤 기준으로 AI 모델을 골랐는지 (작업별 · 규칙 지표 + 채점자 둘)
> * 12개 모델의 작업별 점수 · 시간 · 비용
> * 상황별(맥미니 · API · 회사 서버 · 국산 모델만) 추천

## 1. 평가 방법

* **작업별로 따로:** 요구 수준이 달라서 네 가지로 나눴다.
  * T1 자료 요약 (기사 · 논문 6건)
  * T2 보고서 초안 (2개 주제, 각 자료 8건)
  * T3 기술 흐름 정리 (2개 기술)
  * T4 짧은 작업 (검색어 8개, 정답을 미리 정해 둠)
* **공정하게:** 모든 모델에 **앱의 실제 지시문 · 같은 입력**.
* **규칙 지표:** 근거 정직(「원문 근거」로 표시한 문장이 실제로 원문과 겹치는지 — 앱의 근거 대조 기준 그대로), 원문에 없는 숫자, 고객사 · 경쟁사 기술 혼동, 형식, 시간, 비용.
* **AI 채점자 둘:** Claude Opus 5.5 · GPT-6 Sol이 **모델 이름을 가린 채** 5개 항목(정확 · 근거 · 종합 · 실무 · 한국어)을 채점, 두 점수 평균.
* **믿을 수 있나:**
  * 채점자 일치(순위 상관) 0.71.
  * 각 채점자가 자기 회사 모델에 0.15~0.2점 후한 경향 → 두 채점자 평균으로 상쇄.
  * 같은 모델을 두 번 돌린 차이 평균 0.19 → **0.4 미만 차이는 우연**으로 본다.

## 2. 결과 (5점 만점, 두 채점자 평균)

| 모델 | 요약 | 보고서 | 흐름 | 요약 근거 정직 | 보고서 1건 |
| :-- | :-: | :-: | :-: | :-: | --: |
| GPT-6 Sol | 3.08 | 2.90 | **3.80** | 57% | 25초 |
| Claude Sonnet 5.5 | **3.18** | **2.98** | 3.35 | 72% | 80~89초 |
| GPT-6 Luna | 3.05 | 2.88 | 3.23 | 64% | 41~43초 |
| K-EXAONE 2.5 | 3.12 | 2.40 | 3.00 | **76%** | 무료 API 한도 (18건 31분) |
| Claude Haiku 5.5 | 2.60 | 2.70 | 3.27 | 75% | 41~58초 |
| GPT-5.6 Luna | 2.65 | 2.60 | 2.75 | 62% | 13초 |
| Claude Opus 5.5 | — | 2.65 | 3.15 | — | 55초 |
| Upstage Solar Pro 4 | 2.60 | 2.27 | 2.77 | 71% | 12~21초 |
| Gemma 4 31B | 2.55 | 2.42 | 2.95 | 65% | 12~18초 |
| Gemma 4 26B (Vertex) | 2.45 | 2.67 | 2.35 | 65% | 18~26초 |
| gemma4:26b (맥미니) | 2.34 | 2.50 | 2.85 | 63% | — |
| **gemma4:12b (맥미니, 운영)** | 2.15 | 2.60 | 2.70 | 70% | 약 58초 |

* **요약:** 상용 상위권(3.05~3.18)과 Gemma 계열(2.15~2.55) 사이 0.6~0.9 차이 — 의미 있는 차이.
* **보고서:** 대부분 2.4~3.0, **모델 차이가 작다** — 입력이 이미 요약이라 양식 · 지시문의 영향이 크다.
* **가장 큰 발견:** 모든 모델의 「실무」(고객사 관점) 점수가 1.5~2.3으로 가장 낮다 → **모델보다 요약 양식 개선이 먼저**.
* 최상위 고가 모델(Opus 5.5)은 보고서 점수가 더 낫지 않았다 → 더 비싼 모델은 후보에서 뺐다.

## 3. 상황별 추천

| 상황 | 자료 요약 | 보고서 · 흐름 | 짧은 작업 |
| :-- | :-- | :-- | :-- |
| 맥미니 24GB | gemma4:12b 유지 | gemma4:12b | gemma4:12b |
| API | GPT-6 Luna (근거 정직 중시면 Claude Haiku 5.5) | GPT-6 Sol (대안 Claude Sonnet 5.5) | GPT-6 Luna |
| 회사 서버 (GPU) | Gemma 4 26B | K-EXAONE 공개 가중치 또는 Gemma 4 31B | Gemma 4 26B |
| 국산 모델만 | K-EXAONE 2.5 | K-EXAONE 2.5 (사람 검토 필수) | K-EXAONE 2.5 |

* 맥미니 26B는 12B와 같은 품질 · 1.5배 빠름 · 메모리 2배(17GB). 31B · EXAONE 4.5 33B는 24GB에 안 맞음(실측).
* 뉴스 본문을 외부 상용 AI에 넣는 것은 출처 약관과 걸릴 수 있다 → API로 바꿀 때는 1 · 2차 출처 · 논문 위주로 ([08](08_data_terms.md)).

## 4. 뺀 모델과 이유

| 뺀 것 | 이유 |
| :-- | :-- |
| 12B보다 작은 모델 (Gemma 4 E2B · E4B, 한국어 추가 학습 소형판, EXAONE 2.4B · 7.8B) | 운영 모델보다 작음. 이전 비교에서 이미 약함 |
| 세대가 지난 모델 (GPT-4 · Claude 4 · Gemma 3) | 같은 회사 새 모델이 같은 값에 더 좋음 |
| 최상위 고가 모델 | Opus 5.5로 재 보니 이득 없음 |
| 오류 · 시간 초과 (일부 API) | 8건 중 3건 시간 초과, 8건 모두 공급처 오류 |
| 커뮤니티 한국어 26B 판 | 설치 형식 문제로 출력이 무너져 판단 불가 |

## 5. 이전 비교 (11/07, 팀 채점)

같은 기사 10건 요약 + 보고서 1회를 13개 모델로 만들어 팀이 원문과 대조해 25점으로 채점 → 맥미니에서 돌 수 있는 것 중 최선인 **gemma4:12b**로 교체 (보고서 109초 → 67초, 품질 13.5 → 19점).

## 6. 한계

* 표본이 작다 — 요약 6건, 보고서 · 흐름 각 2주제(주요 모델 2회). 큰 차이(요약 0.6 이상)만 믿을 만하다.
