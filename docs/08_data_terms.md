# 08. 데이터 · 약관 · 회사 도입

> **이 문서로 알 수 있는 것**
> * 모으는 데이터마다 이용 조건
> * 회사 안에서 쓸 때 무엇이 가능하고 무엇을 확인해야 하는지

<sub>팀 검토이며 법률 자문이 아닙니다. 실제 도입 전 회사 법무 확인이 필요합니다.</sub>

## 1. 데이터별 이용 조건

| 대상 | 사내 업무 | 조건 |
| :-- | :-- | :-- |
| 논문 (OpenAlex · Crossref 등) | 가능 | OpenAlex 데이터 CC0 · 출처 표시 |
| 특허 (Google Patents) | 가능 | CC BY 4.0 — 출처 표시 |
| RSS 28곳 · 기사 원문 | 조건부 | **제목 · 요약 · 링크만** 저장, 원문은 보고서에 고른 것만 90일 |
| 네이버 뉴스 | 막힐 수 있음 | 약관: AI 입력 제한 · 보관 기간 → 「21일만 보관」 스위치 준비 |
| 공개 AI 모델 (Gemma 4 · Qwen · gpt-oss · Mistral) | 가능 | Apache 2.0 등 상업 사용 허용 |
| 일부 연구용 모델 (소형 EXAONE · 일부 예측 모델) | 별도 계약 | 연구 · 교육 전용 → 계약 확인 |
| 외부 AI API (OpenRouter 등) | 기본 끔 | 입력이 회사 밖으로 나감 |

## 2. 회사 안에 둘 때

* **앱 · DB는 그대로**, 바뀌는 곳은 두 곳 ([02](02_architecture.md)):
  1. AI → 사내 GPU의 공개 모델 (Gemma 4 26B / 31B — 상업 사용 허용)
  2. 수집 → 인터넷 쪽 서버에서, 업무망에는 결과 파일(PDF · PPT)만
* 사내 문서는 「직접 추가 자료」로 넣는다.
* 확인할 것: 뉴스 약관 · 원문 저장 범위 · 모델 계약 · GPU 서버 · 업무망 반입 절차.
* 망 구역별 설치 위치 · 비용은 [12 회사 안에 설치하기 · 비용](12_onprem_cost.md).

## 3. 저장하지 않는 것

* 기사 원문 전체 (고른 것만 기간을 두고)
* 개인정보 (사용 기록은 브라우저 무작위 번호로만, 이름 · IP를 보고서에 남기지 않음)
* API 키는 관리 페이지에서 넣으면 서버 암호 열쇠로 잠가 저장, 화면에 다시 보이지 않음
