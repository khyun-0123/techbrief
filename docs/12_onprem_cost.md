# 12. 회사 안에 설치하기 · 비용

> **이 문서로 알 수 있는 것**
> * 회사 망 안 **어디에** 무엇을 두는지 (구체적인 설치 시나리오)
> * AI를 회사 안에 두려는 이유 세 가지
> * 사용 규모 · AI 선택별 **월 비용** (실측 토큰 기준)

## 1. 어디에 두나 — 설치 시나리오

회사 망은 보통 둘로 나뉜다.

| 구역 | 무엇이 있나 | 인터넷 |
| :-- | :-- | :-- |
| **업무망 (폐쇄망)** | 결재 · 사내 문서 · 내부 시스템 | 막힘 |
| **사내 인터넷망** | 인터넷용 업무 PC · 사내 서버 일부 | 나가는 연결만 (방화벽 안) |
| 회사 밖 | 클라우드 · 외부 서비스 | — |

테크브리프는 **사내 인터넷망**에 둔다. 인터넷으로 공개 자료를 모아야 하지만, 회사 밖(클라우드)에 둘 필요는 없다.

| 무엇 | 어디에 | 어떻게 연결 |
| :-- | :-- | :-- |
| **앱 서버** (화면 + API) | 사내 인터넷망의 서버 1대 (가상 서버 2코어 · 8GB면 시작 가능) | 직원은 사내 주소(`http://내부주소:포트`)로만 접속 — **외부 공개 주소 없음** |
| **DB** (PostgreSQL) | 같은 서버 또는 옆 서버 | 앱만 접속, 백업도 사내 |
| **AI 모델 서버** | 같은 구역의 사내 GPU 서버 | 앱이 OpenAI 호환 API로 호출 (`http://AI서버:8000/v1`) — 관리 페이지에 주소만 넣으면 끝 |
| 수집 | 앱 서버에서 **밖으로 나가는 요청만** | 네이버 뉴스 · RSS 28곳 · 논문 API · 특허(분기 1회) — 방화벽에서 이 주소만 허용 |
| 결과물 | 보고서 PDF · PPT | 업무망에는 망연계로 파일만 옮김 |

**회사 밖으로 나가는 것:** 수집 키워드(검색 요청)뿐. 사내 자료 · 보고서 초안 · AI 입력은 나가지 않는다.
**밖에서 들어오는 것:** 공개 자료(기사 · 논문 · 특허)뿐. 밖에서 테크브리프로 접속할 길은 없다.

> 지금 시연 구성이 이 구조의 축소판이다 — 앱 · DB는 서버에, AI는 **따로 켜 둔 모델 서버(맥미니)**에 두고 API로 연결했다. 회사에서는 맥미니 자리에 사내 GPU 서버가 들어간다. 코드는 그대로, 주소만 바뀐다 ([02](02_architecture.md) · [11](11_setup_handover.md)).

## 2. 왜 AI를 회사 안에 두려 하나

**① 회사 정보가 밖으로 나가지 않는다 — 마음 편히 쓸 수 있다**

* 담당자가 올리는 내부 자료, 「우리 회사에 위협인가 기회인가」라는 판단, 보고서 초안 — 모두 회사 안 AI에서만 처리된다.
* 외부 AI는 공개 기사까지만 넣을 수 있다. 내부 자료를 넣는 순간 외부 API는 쓸 수 없다.

**② 테크브리프는 「쓸 때만 도는 AI」가 아니다**

* 일반적인 AI 도구: 사람이 물을 때 AI가 돈다 → 종량제(쓴 만큼 결제)가 맞다.
* 테크브리프: **밤사이 미리 모으고 · 미리 요약하고 · 미리 분석해 두었다가**, 사람이 요청하면 기다림 없이 내놓는다. AI가 사람 요청과 상관없이 하루 종일 돈다.
* 그래서 회사 안 AI 서버와 잘 맞는다 — **사람이 없는 밤 · 주말의 빈 시간을 채우고**, 낮에는 사람 요청을 먼저 처리한다 (앱의 AI 순서 규칙: 사람 요청 → 보고서 → … → 자동 요약). 서버 가동률이 올라간다.

**③ AI 장비는 「지금 확보하려는」 자산이 되고 있다**

* 팀장이 정부혁신박람회 기업 부스를 돌며 들은 이야기: 예전에는 AI 서버의 감가가 크다고 보고 **구독 · 월정액 외부 API**를 택한 곳이 많았다. 그런데 AI 수요가 급증하면서 **장비 값이 오르고 구하기도 어려워져**, 가능하면 자체 AI 장비를 갖추려는 기업이 많다.
* 시장 자료도 같은 방향이다 (2026년 기준, 출처마다 수치 차이 큼):
  * 서버용 메모리 계약가가 2026년 크게 오르고, 주요 서버 제조사가 1분기에 약 15% 인상 · 납기 4~8주 이상 ([Relutech](https://relutech.com/blogs/hardware/the-2026-server-hardware-crisis) · [Microchip USA](https://www.microchipusa.com/industry-news/ai-hardware-shortage-beyond-gpus))
  * GPU 서버 가격이 2025년 초보다 30~50% 높다는 전망, 엔비디아가 2027년 초 출하분 15% 이상 인상을 알렸다는 보도 ([Hostkey](https://hostkey.com/blog/152-server-price-increases-in-2026-forecasts-causes-and-recommendations/) · [Shattered](https://shattered.io/nvidia-ai-server-price-hike-memory-shortage-2026/))
  * 96GB GPU(RTX PRO 6000)가 출시가의 약 2배인 1.6만 달러 ([Wccftech](https://wccftech.com/nvidia-96-gb-rtx-pro-6000-blackwell-now-costs-16000-usd-double-its-original-price/))
* 회사가 AI 서버를 갖추면, 테크브리프는 그 위에서 **매일 도는 첫 업무**가 될 수 있다.

## 3. 월 비용 — 규모 · AI 선택별

### 3-1. 사용량 가정

| 작업 | 1건 토큰 (실측) | 시범 (1팀) | 전사 (10팀) |
| :-- | :-- | --: | --: |
| 자료 요약 (자동 + 사람) | 입력 약 2,400 · 출력 약 600 | 하루 230건 | 하루 1,400건 |
| 보고서 (자료 40건 = 조각 4 + 합치기 1) | 입력 약 2.8만 · 출력 약 7,500 | 하루 5건 | 하루 50건 |
| 기술 흐름 정리 | 입력 약 3,400 · 출력 약 1,000 | 하루 10건 | 하루 100건 |
| **한 달 (30일)** | | **약 2,700만 토큰** | **약 1.9억 토큰** |

* 토큰 수는 [06 모델 평가](06_model_evaluation.md)에서 앱의 실제 지시문으로 잰 값(Gemma 4 기준), 요약 입력은 운영 서버 크기로 잰 값.
* 11/27 운영 서버: 밀린 자동 요약 0건 — 새로 들어온 「중요」 자료만 요약하므로 시범 규모 가정은 넉넉한 편.
* 상용 모델은 같은 일에 더 길게 쓴다(출력 1.5~9배) → 같은 평가에서 **그 모델이 실제로 쓴 토큰 × 공식 단가**로 계산.

### 3-3. 장비 · 서버 비용

| 구성 | 처음 | 월 환산 | 보고서 1건 | 비고 |
| :-- | --: | --: | :-- | :-- |
| 공개 데모 (지금) — 클라우드 서버 + 맥미니 AI | — | 서버 약 $55 · 맥미니 전기 약 0.4천 원 | 약 11분 (맥미니 12B) | 운영진 지원 계정 |
| 사내 앱 + DB 서버 | 기존 가상 서버 활용 시 거의 없음 | — | — | 2코어 · 8GB · 디스크 100GB+ |
| 사내 소형 AI — 맥미니급 (메모리 24GB) | 약 150만~200만 원 (구성에 따라) | 상각 약 4만~5.5만 원 + 전기 | 약 11분 | 지금 시연 장비. 1팀 시범까지 |
| 사내 GPU 서버 — 96GB GPU 1장 | 약 4,900만 원 ($35,000, [B3IQ 1장 구성](https://b3iq.org/machines/rtx-pro-6000) 기준) | 상각 약 136만 원 + 전기 약 11만 원 | 약 2분 (추정 — Vertex와 같은 모델 급) | 26B · 31B 여유, 다른 AI 업무와 함께 |

* 상각은 3년 정액. 전기는 산업용 평균 185.5원/kWh ([2026년 6월 기사](https://www.kukinews.com/article/view/kuk202606220018)), GPU 서버 평균 0.8kW 가정.
* 테크브리프 시범 규모가 GPU 서버를 쓰는 시간은 하루 1시간 미만으로 추정 (출력 하루 약 18만 토큰) — 나머지는 회사의 다른 AI 업무 몫.

### 3-4. 어떻게 읽나

* **비용만 보면 오픈 모델 API가 가장 싸다** — 시범 월 1만 원 안팎, 전사도 10만 원 안쪽. 테크브리프 하나를 위해 GPU 서버를 사는 것은 비용으로는 맞지 않는다.
* 그래도 회사 안 AI를 지향하는 이유는 **비용이 아니라 ①정보 보안 ②상시 가동 ③장비 확보 추세**다 (2장). 회사가 AI 서버를 갖추는 순간 테크브리프의 AI 비용은 전기료 수준이 된다.
* 상위 상용 모델을 전사 규모로 쓰면 월 약 340만 원 — GPU 서버 월 환산(약 147만 원)의 2배를 넘는다.
* **단계별 추천:** 시범은 지금처럼 소형 AI 서버(또는 공개 자료만 넣는 조건으로 오픈 모델 API) → 회사 AI 서버가 생기면 주소만 바꿔 옮긴다.

## 4. 한계

* 장비 가격은 2026년 8~11월 해외 판매가 · 집계 기준이며 국내 견적이 아니다. 메모리 가격 변동이 커서 실제 견적이 필요하다.
* 사내 GPU 서버의 보고서 시간(약 2분)은 같은 모델의 클라우드 실측에서 옮긴 추정이다.
* 사용량은 가정이다. 시범 사용에서 실제 요약 · 보고서 건수를 앱 기록으로 다시 잰다.
* API 단가는 11/27 공식 가격표 정가. 가격은 바뀔 수 있고, OpenRouter는 요청을 보낸 공급사에 따라 달라진다.
